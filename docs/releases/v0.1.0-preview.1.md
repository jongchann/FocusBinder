# FocusBind v0.1.0-preview.1

Windows x64용 첫 시험 배포입니다. 실제 게임 호환성 검증은 진행 중입니다.

## 다운로드와 실행

1. `FocusBind-0.1.0-preview.1-win-x64.zip`을 내려받아 폴더 전체를 압축 해제합니다.
2. 폴더 안의 `FocusBind.App.exe`를 실행하고 관리자 권한 요청을 승인합니다.
3. 대상 창을 선택해 키 바인딩을 편집·저장하고 편집기를 닫은 뒤 매핑을 시작합니다.

.NET 런타임을 포함한 self-contained 포터블 패키지입니다. 별도 .NET 설치는 필요하지 않습니다. ZIP 내부 DLL·리소스는 함께 유지하세요. Windows 10/11 x64를 대상으로 하며 설치 프로그램·자동 업데이트·디지털 서명은 포함하지 않습니다.

## 포함 기능

- 창별 프로필, 키·조합키·마우스 버튼·휠 트리거
- 좌표 클릭, 빠른 이동·클릭·복원, 키·마우스·휠 출력, 지연·중첩 반복
- 창 조건·액션 목록·레이아웃·콘텐츠·3×3 앵커 편집
- 실제 입력 없는 매핑 테스트, 프로필 JSON 가져오기·내보내기·복구
- 포커스된 앱의 음량·음소거 전역 단축키
- 실행 파일 기준 단축키 오버레이, 투명도 설정, 전역 토글

기본 전역 단축키: Ctrl+Alt+F6 매핑 시작/종료, F7/F8 음량 증가/감소, F9 음소거 토글, F10 오버레이 토글. 메인에서 변경할 수 있습니다. 오버레이는 기본 꺼짐이며 설정에서 대상 프로세스를 선택해야 합니다.

## 저장·업데이트·제거

설정은 `%LOCALAPPDATA%\FocusBind`에 저장합니다. 업데이트 전 프로필을 내보내고 해당 폴더를 백업하세요. 앱을 종료한 뒤 새 ZIP을 별도 폴더에 압축 해제해 실행하면 같은 설정을 사용합니다. 제거는 앱 종료 후 압축 해제한 프로그램 폴더를 삭제하면 됩니다. 사용자 설정은 자동 삭제하지 않습니다.

## 검증과 알려진 제한

- 자동 시나리오 37개 및 오프라인 WPF 편집기·오버레이 검증 통과.
- 릴리스 패키지는 x64 실행 파일 구성·포함 런타임·WPF 리소스·핵심 좌표 계산·편집기 생성 경로를 입력 주입 없이 검사합니다. 자동 환경에서는 DLL 진입점으로 실행하고 .NET 및 WPF 라이브러리가 압축 해제한 패키지에서 로드되는지 확인했습니다.
- 실제 EXE의 UAC 승인과 일반 앱·게임에서의 대화형 시작은 별도 검증이 필요합니다.
- 실제 대상 게임 클릭 정확도, 클릭 통과, DPI·다중 모니터·게임 표시 모드 호환성은 미검증입니다. 모의 실행 완료는 게임 클릭 성공을 의미하지 않습니다.
- Unity 창 메시지 클릭은 차단됩니다. 커서 이동 또는 빠른 클릭 모드를 사용하세요.
- 조건 분기·시퀀스 호출, 프로필별 동시 실행/재시작 정책, 방향 제어, 캡처 영속화, 트레이 메뉴는 아직 미지원입니다. Lua는 보류입니다.

다운로드 무결성은 함께 게시한 `SHA256SUMS.txt`와 PowerShell `Get-FileHash -Algorithm SHA256` 결과를 비교하세요. 문제를 보고할 때 앱 버전·대상 앱·창 크기·DPI·재현 순서와 기대/실제 결과를 포함하세요. 진단 로그는 사용자 설정 폴더에 있습니다.
