# FocusBind v0.1.0-preview.3

휠 조합키와 공유 프로파일 병합, 모서리 기준 좌표 설정을 추가한 Windows x64 시험 배포입니다.

## 변경 사항

- **Ctrl·Alt·Shift·Win + 휠**을 입력 트리거와 휠 출력에서 각각 설정할 수 있습니다. 방향 변경·저장·다시 선택 시 보조키를 유지하며, 실행기가 누른 키만 정리합니다.
- **전역 단축키 편집 개선**: 보조키 체크와 키 목록 직접 선택을 제공합니다. IME·Alt 조합에서 Ctrl+Alt+알파벳 기록이 누락되던 문제를 수정했습니다.
- **기본 단축키**: 매핑 시작/종료 Ctrl+Alt+Z, 음량 증가/감소 Ctrl+Alt+F7/F8, 음소거 Ctrl+Alt+P, 프로세스 오버레이 Ctrl+Alt+O입니다. 기존 저장 설정은 유지합니다. 새 기본값을 쓰려면 전역 단축키 변경 → 기본값 복원 → 저장 및 적용을 누르세요. 이때 다른 기능의 기본값도 함께 복원됩니다.
- **프로파일 가져오기 충돌 선택**: 같은 ID 또는 이름이 있으면 프로파일별로 병합·복사본 추가·건너뛰기를 선택합니다. 기본은 복사본 추가이며 병합할 대상도 직접 고를 수 있습니다. 병합은 기존 설정과 같은 ID·단축키의 매핑을 유지하고 새 매핑·필요한 레이아웃을 추가합니다. 기존 창 선택과 가져오기 전 백업을 유지합니다.
- **모서리·중앙 기준 고정 거리 좌표**: 3×3 기준점에서 물리 픽셀 거리를 유지합니다. 우하 기준 X -80 / Y -40은 오른쪽·아래에서 80px·40px 거리를 유지합니다. 오른쪽 클릭 위치 패널에서 모드·기준점·거리를 편집하며 기준점 변경 시 현재 위치를 보존합니다.
- **좌표 재지정 수정**: 마커 드래그와 화면에서 지점 선택이 기존 좌표 공간·앵커를 유지합니다. 비례 앵커와 고정 픽셀 설정이 비율 좌표로 바뀌던 문제를 해결했습니다.
- README를 기능 소개·설정 화면 예시·빠른 시작·좌표/휠/오버레이 설정·프로파일 공유·문제 해결 순서로 정리했습니다.

## 다운로드·업데이트

`FocusBind-0.1.0-preview.3-win-x64.zip` 전체를 새 폴더에 압축 해제하고 `FocusBind.App.exe`를 실행하세요. .NET 런타임을 포함하며 관리자 권한 요청을 승인해야 합니다. 이전 앱을 종료한 뒤 업데이트하세요.

설정은 `%LOCALAPPDATA%\FocusBind`에 유지됩니다. 업데이트 전 이 폴더를 백업하세요. ZIP에는 개인 프로파일이나 계정 정보를 포함하지 않습니다. 진단 로그는 기본 꺼짐이며 기존에 켜서 저장한 선택은 유지됩니다.

새 `anchoredPixelOffset` 좌표를 사용하는 프로파일은 이 버전 이상에서 사용하세요. 기존 프로파일의 좌표와 저장된 단축키는 자동 변경하지 않습니다. 공유할 때 실행 파일 경로가 다르면 창 조건을 수정하거나 경로를 비우고 실행 파일 이름·창 클래스로 지정하세요.

## 검증과 제한

- 핵심 자동 시나리오 **45개** 통과: 휠 조합·안전 해제, 프로파일 병합·원본 보존, 고정 거리의 리사이즈·9개 기준점·저장/복원 등을 검사합니다.
- Debug 빌드 경고·오류 0, 오프라인 WPF 단축키/좌표/병합 UI 검증, Release self-contained ZIP의 압축 해제·파일 해시·앱 로컬 .NET/WPF 런타임·리소스·편집기 생성 검증을 수행합니다.
- 실제 UAC 승인과 게임 클릭 수용, 창 크기/DPI·다중 모니터·전체 화면 오버레이 호환성은 별도 확인이 필요합니다. 모의 실행 성공은 실제 게임 클릭 성공을 뜻하지 않습니다.
- Unity 창에서는 창 메시지 클릭을 차단합니다. 커서 이동 또는 빠른 이동·클릭·복원을 사용하세요. 휠은 현재 커서 위치에 출력합니다.
- 조건 분기·시퀀스 호출은 실행 미지원이며 Lua는 보류입니다. 설치 프로그램·자동 업데이트·디지털 서명은 포함하지 않습니다.

프로그램 폴더를 삭제하면 제거되며 사용자 설정은 남습니다. `SHA256SUMS.txt`로 ZIP 무결성을 확인할 수 있습니다.
