# FocusBind v0.1.0-preview.2

진단 로그를 선택형으로 변경한 Windows x64 시험 배포입니다.

## 변경 사항

- Debug·Release 모두 로그 기록 기본값을 **꺼짐**으로 변경했습니다. 기본 상태에서는 diagnostics/shortcuts 로그 파일이나 로그 작성 작업을 생성하지 않습니다.
- 메인 **창 정보와 진단 → 진단 로그 파일 기록 (기본 꺼짐)**에서 배포본도 직접 켜고 끌 수 있습니다.
- 실행 중 변경이 즉시 반영됩니다. 끄면 입력·단축키 로그 작성기를 닫고 대기 중인 기록을 버립니다. 다시 켜면 새 파일에 기록합니다. 매핑이나 단축키를 재시작할 필요가 없습니다.
- 선택은 `%LOCALAPPDATA%\FocusBind\logging.json`에 저장됩니다. 설정 파일이 없거나 읽을 수 없으면 꺼짐으로 시작합니다. 사용자가 켜서 저장한 경우에는 다음 실행에도 켜짐을 유지합니다.
- 꺼진 상태에서는 로그 파일 경로를 표시하지 않습니다. 화면의 오류 안내·진단 카운터와 무입력 테스트 창은 계속 사용할 수 있습니다.

기존 로그 파일은 자동 삭제하지 않습니다. 이 버전으로 바꿔도 실행 중인 이전 앱의 동작은 바뀌지 않으므로 먼저 이전 앱을 종료하세요.

## 다운로드·업데이트

`FocusBind-0.1.0-preview.2-win-x64.zip`을 내려받아 전체를 새 폴더에 압축 해제하고 `FocusBind.App.exe`를 실행하세요. .NET 런타임이 포함되어 별도 설치가 필요하지 않습니다. 관리자 권한 요청을 승인해야 합니다.

사용자 설정은 기존 `%LOCALAPPDATA%\FocusBind` 폴더를 사용합니다. 업데이트 전 해당 폴더를 백업하세요. ZIP에는 사용자 설정을 포함하지 않습니다. 제거는 앱 종료 후 압축 해제한 프로그램 폴더를 삭제하면 되며 사용자 설정은 유지됩니다. 설치 프로그램·자동 업데이트·디지털 서명은 포함하지 않습니다.

## 검증과 제한

- 자동 시나리오 **40개** 통과: 기본 꺼짐에서 파일/폴더 미생성, 동시 기록 중 즉시 비활성화, 재활성화 시 새 파일, 이후 생성한 로거의 정책 적용, 설정 저장·재로드를 검증했습니다.
- 기본 경로 빌드 경고·오류 0개, 오프라인 WPF UI 및 패키지 로컬 .NET/WPF 리소스·편집기 생성·기본 로그 꺼짐 검증.
- 실제 UAC 승인·일반 앱/게임의 대화형 시작, 대상 게임 클릭·오버레이 통과·DPI·다중 모니터 호환성 검증은 남아 있습니다. 모의 실행 완료는 실제 게임 클릭 성공을 뜻하지 않습니다.
- 기존 기능과 미지원 범위는 [이전 릴리스](v0.1.0-preview.1.md)와 같습니다. Lua는 보류입니다.

`SHA256SUMS.txt`로 ZIP 무결성을 확인할 수 있습니다.
